# essmos/nonodb

The all-in-one JSON document database(Mongodb style) for small VMs and edge boxes. ~5 MB idle RAM,  BM25/fuzzy/vector search, SQL, encrypted backups, replication, and GUI. Mongo style query. MIT licensed.
