# JostQQ/tradingview-mcp

Comprehensive MCP server for TradingView Desktop: complete Pine Script lifecycle (create/save/version), full Strategy Tester extraction (every metric, every trade), chart and layout control, replay, alert/watchlist tools and DOM-driven UI automation over Chrome DevTools Protocol. No computer vision.
