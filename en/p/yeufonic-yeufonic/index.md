# yeufonic/yeufonic

A web interface (and more) for YuE2: cover a recording or write a song from a prompt, edit the score, extract the stems, create your own LoRA, import them, export them, share them with fellow yeufonic users. Installs via Docker containers on Linux or Windows. or directly via an installer for Windows and MacOS.
