# GigaEtherealos/resp-local-generative-colab-skill

Skill that drives a visual-reconstruction, editable-asset-extraction, 3D, audio, voice and video-generation pipeline from a local Linux controller on a remote cloud GPU (Google Colab or Kaggle) via the Colab/Kaggle CLI - with a model-discovery protocol that researches the best specialist model for each task.
