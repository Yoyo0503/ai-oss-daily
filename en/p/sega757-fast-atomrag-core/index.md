# Sega757/Fast-AtomRAG-Core

Lightweight, zero-broker hybrid retrieval engine for RAG. Combines vector search, local Personalized PageRank (PPR) over Atomic Entity Graphs (AEG), and Reciprocal Rank Fusion (RRF). Features SLA-driven cost-aware routing and strict SQLite WAL persistence. Built for extreme low-latency and AI agent orchestration.
