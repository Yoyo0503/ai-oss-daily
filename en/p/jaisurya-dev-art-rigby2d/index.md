# jaisurya-dev-art/rigby2d

Open-source 2D skeletal animation editor for games and film. AutoRig layered PSDs, animate with meshes, IK and physics, lip-sync from audio, render video, export JSON/.skel. JavaScript, Rust and Godot runtimes. Built-in MCP server for AI assistants. Docs: jaisurya-dev-art.github.io/rigby2d/docs
