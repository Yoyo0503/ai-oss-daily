# johnrobinsn/AvatarVoice

Real-time voice chat with a lip-synced diffusion head-avatar (AvatarForcing). WebRTC server, VAD/STT/LLM/TTS loop, and a streaming infrastructure that keeps the model running indefinitely on one GPU.
